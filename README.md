
# 📊 Power BI Executive Sales Dashboard

## 📌 Project Overview

This project is an interactive Power BI Executive Summary Dashboard designed to provide a clear overview of business sales performance.

The dashboard helps analyze sales, customers, orders, profit, product categories, payment methods, and sales channels.

## 📊 Dashboard Visualizations

The dashboard includes:

- Monthly Net Sales Analysis
- Net Sales by Category
- Profit by Category
- Sales Amount by Store Type
- Net Sales by Product
- Sales by Payment Method

## 🎛️ Filters

Users can interact with the dashboard using:

- Year
- Month
- Category
- Region
